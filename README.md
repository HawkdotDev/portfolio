# Portfolio Website

> A dynamic, interactive portfolio website built with React and TailwindCSS, featuring a hand-drawn, sketchy aesthetic.

## Features

- **WIP - Currently Under Construction**
- **Hand-Drawn Sketchy Style**: All borders, separators, and design elements utilize custom SVG paths for an organic, hand-drawn look.
- **Dynamic Avatar**: Features a prominent avatar section that adapts to the user's screen size.
- **Contact Form**: A functional contact form with real-time validation and instant feedback.
- **Interactive Timeline**: A skills and experience timeline with hover effects and category filtering.
- **Project Gallery**: A grid layout for showcasing projects with hover interactions.
- **Cat Toasts**: A unique notification system that uses cat images for feedback.
- **Responsive Design**: Built with TailwindCSS for seamless display across all devices.
- **Smooth Animations**: Implemented using Framer Motion for fluid transitions and micro-interactions.

## Tech Stack

- **Framework**: React 18+
- **Styling**: TailwindCSS 4
- **Animation**: Framer Motion
- **Icons**: Lucide React
